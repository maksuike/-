# ДИМАР — сайт крафтового BBQ-виробництва на Django

Світла тема в стилі типового BBQ-магазину (топбар з контактами, картки товарів
з фото, кошик, оформлення замовлення) + анімації при скролі й наведенні.
Контент, бренд, товари — власні, вигадані для демонстрації.

## Запуск
```
python3 -m venv venv
source venv/bin/activate
pip install django pillow
python manage.py migrate
python manage.py seed_menu      # наповнює асортимент, переваги й магазини
python manage.py createsuperuser
python manage.py runserver
```
Сайт: http://127.0.0.1:8000/
Адмінка: http://127.0.0.1:8000/admin/

## Що реалізовано
- **Кошик на сесіях** (`menu/cart.py`) — додавання, зміна кількості, видалення, без БД для гостя
- **AJAX "Додати в кошик"** — без перезавантаження сторінки, з тостом і анімацією лічильника; якщо JS вимкнено, форма працює звичайним POST-редіректом
- **Оформлення замовлення** (`/checkout/`) — ім'я, телефон, адреса, коментар → створює `Order` + `OrderItem` в базі
- **Підтвердження замовлення** — сторінка успіху з номером і підсумком
- **Адмінка замовлень** — усі замовлення видно в `/admin/`, зі статусом (нове / підтверджено / виконано) і складом
- **Фото товарів** — поле `image` на товарі; без фото показується кольоровий плейсхолдер
- **Анімації** — scroll-reveal, hover на картках, тінь хедера при скролі, дим у хіро-блоці

## Чого свідомо немає (наступні кроки)
- Реальної оплати — інтеграція з платіжним провайдером (LiqPay/Fondy/Stripe) не підключена, це окрема інтеграція з реальними ключами продавця
- Email/SMS-сповіщень про нове замовлення
- Логіну для клієнтів / історії замовлень

## Структура
- `menu/cart.py`, `menu/views.py`, `menu/urls.py` — логіка кошика й чекауту
- `menu/models.py` — MenuCategory, MenuItem, StoreLocation, Feature, Order, OrderItem
- `menu/templates/menu/` — base, home, cart, checkout, order_success
- `menu/static/menu/style.css`, `app.js` — дизайн і поведінка
